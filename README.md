# 🏠 Housing Price Prediction (Machine Learning Project)

This project is a beginner-friendly Machine Learning pipeline built using Python and Scikit-Learn.  
The goal is to predict **median house prices** using the California Housing dataset.

---

## 📌 Project Objective

Build a regression model that predicts housing prices based on features such as:
- Median income
- Average number of rooms
- Population
- Geographical location (latitude/longitude)

---

## 📊 Dataset

We use the built-in **California Housing dataset** from Scikit-Learn.

It contains data collected from the 1990 California census.

Features include:
- `median_income`
- `housing_median_age`
- `total_rooms`
- `total_bedrooms`
- `population`
- `households`
- `latitude`
- `longitude`

Target:
- `median_house_value`

---

## ⚙️ Technologies Used

- Python 🐍
- NumPy
- Pandas
- Matplotlib
- Scikit-Learn

---

## 🧠 Machine Learning Workflow

The project follows a standard ML pipeline:

1. Data loading
2. Exploratory Data Analysis (EDA)
3. Data preprocessing
4. Train-test split
5. Feature scaling
6. Model training (Linear Regression)
7. Model evaluation

---

## 📈 Model Used

- Linear Regression

Evaluation metrics:
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score
